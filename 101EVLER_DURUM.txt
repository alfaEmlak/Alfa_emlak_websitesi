1) ŞU ANA KADAR YAPILANLAR
--------------------------------------------------------------------------------

A. Veritabanı (Supabase)
   - listings tablosuna iki yeni kolon:
       * export_to_101evler  (boolean) — bu ilan 101evler'e gönderilsin mi?
       * ext_101evler        (jsonb)   — type_id, area_id, room_count_id,
                                          build_age_id, furnishing_id,
                                          billing_cycle_id, title_type_id,
                                          price_for, reference_no
   - listings tablosuna performans için partial index
       (idx_listings_export_101evler)
   - site_settings tablosuna ext_101evler (jsonb) kolonu
       (first_realtor_id, second_realtor_id için)

   Migration dosyası: supabase-migration.sql (sonuna eklendi).

B. Backend / API
   - Yeni endpoint: GET /api/feeds/101evler.xml?token=<TOKEN>
       * Token korumalı (yanlış token → 401)
       * publish_status='PUBLISHED' VE export_to_101evler=true olan ilanları
         101evler XML şemasına göre üretir.
       * ?debug=1 parametresi eklersen JSON özeti döner
         (toplam, dahil edilen, atlanan ilanlar + sebep).
       * Para birimi sadece TRY/USD desteklenir (PDF'te belgelenenler).
         EUR/GBP gelirse o ilan "unsupported_currency" sebebiyle atlanır.

   Yeni dosyalar:
     - lib/feeds/101evler-constants.ts   (PDF'teki tüm lookup tabloları)
     - lib/feeds/101evler-builder.ts     (XML üretici)
     - app/api/feeds/101evler.xml/route.ts (HTTP endpoint)

C. Admin paneli
   - İlan Düzenle ekranına 6. adım eklendi: "101evler"
     Bu adımda doldurulacak alanlar:
       [ ] Bu ilanı 101evler'e gönder (checkbox)
       *   İlan Tipi (type_id)            — ZORUNLU (Villa, Daire, Arsa, …)
       *   Bölge (area_id)                — ZORUNLU (Girne Merkez, vb.)
           Şehir filtresi ile bölgeler kısaltılabilir.
       -   Koçan Türü (title_type_id)
       -   Oda Sayısı (room_count_id)     — 1+0, 2+1, 3+1, …
       -   Bina Yaşı (build_age_id)
       -   Eşya Durumu (furnishing_id)
       -   Kira Ödeme Dönemi              — sadece kiralık ilanlarda
       -   Fiyat Tipi (T=Toplam / U=Birim)
       -   Referans No (boş bırakılırsa ilan numarası kullanılır)

   - Site Ayarları sayfasında "101evler entegrasyonu" bölümü:
       - First realtor ID, Second realtor ID alanları
       - Feed URL bilgisi gösterimi

D. .env yapılandırması
     FEED_101EVLER_TOKEN   — feed URL'inin token'ı
     NEXT_PUBLIC_SITE_URL  — XML'deki <url> alanı için (örn. ilan linki)

3) 101EVLER'DEN İSTENECEKLER
--------------------------------------------------------------------------------

Aşağıdaki bilgiler olmadan feed eksik gönderilir veya bazı ilanlar atlanır.
101evler hesap yöneticisine yazılı olarak şunları sor:

A) Realtor ID'leri
   - Alfa Emlak için <first_realtor_id> değeri nedir?
   - Eğer ikinci bir danışman atayacaksak <second_realtor_id> değeri nedir?
   (Birden fazla danışman / ofis varsa hepsinin ID listesini iste.)

B) Para birimi kodları
   PDF'te yalnızca iki örnek var:
       601 = (muhtemelen) TRY
       602 = (muhtemelen) USD
   Sor:
   - EUR için <currency> kodu nedir?
   - GBP için <currency> kodu nedir?
   - Doğrulama: 601 TRY mi, 602 USD mi (yoksa farklı mı)?

   Cevap geldiğinde lib/feeds/101evler-constants.ts içindeki
   CURRENCY_CODE_MAP'e ekleyeceğim. Şu an EUR/GBP ilanlar feed'den düşüyor.

C) Fotoğraf grup ID'leri (opsiyonel)
   Şu an her fotoğrafta <group_id> göndermiyoruz (PDF zorunlu olmadığını
   söylüyor). 101evler bu alanı kullanışlı buluyorsa:
   - "Kapak fotoğrafı = group_id 1 (Dış Görsel)" yaklaşımı uygun mu?
   - Yoksa her fotoğraf için ayrı kategorize gerekli mi?

D) Feed çağrı sıklığı ve zaman aralığı
   - 101evler feed'i ne sıklıkta çekecek? (saatlik, günlük?)
   - Belirli bir zaman penceresi mi tercih ediyorsunuz?
     (rate-limit ayarı yapmamız gerekirse bilelim)

E) Hata bildirimi
   - Import sırasında hata olursa nereye / nasıl bildirilir?
     (E-posta, dashboard, vs.)
   - Reddedilen ilanların ad_key listesini paylaşabiliyorlar mı?
     (Bizde "skipped" listesi tutuyoruz; karşı tarafta "rejected" varsa
      iki listeyi birleştirip admin paneline gösterebiliriz.)

F) Test ortamı
   - Canlıya geçmeden önce staging / test feed URL'i kabul ediyor musunuz?
   - Yoksa direkt prod feed'i mi vereceğiz?


4) 101EVLER'E SUNULACAKLAR
--------------------------------------------------------------------------------

A) Feed URL'i (TEK ŞEY — onlara verilecek olan bu)
   Format:
       https://www.alfaemlak.com/api/feeds/101evler.xml?token=<TOKEN>

   - <TOKEN> .env.local içindeki FEED_101EVLER_TOKEN değeridir.
     (Rastgele 32+ karakter; tahmin edilemez olmalı, e-postayla değil
      güvenli kanaldan paylaş.)
   - URL canlı (production) olduğunda 101evler bu URL'i belirledikleri
     periyotta otomatik çekecek.

B) Yetkili kişi
   - Alfa Emlak tarafından bir teknik yetkili: ad-soyad, e-posta, telefon
     (sorun çıkarsa 101evler kime ulaşacak?)

C) İmza / sözleşme süreci
   - 101evler'in import için ek belge / yetki taahhüdü istemesi olası;
     onların formatına göre imzalı belge gerekiyorsa hazırla.


5) AKIŞ ÖZETİ (SİZİN VE 101EVLER'İN PERSPEKTİFİNDEN)
--------------------------------------------------------------------------------

Bizim tarafta:
   1. Admin panelden ilana gir → "101evler" adımı → bilgileri doldur,
      "Bu ilanı 101evler'e gönder" işaretle, kaydet ve yayınla.
   2. Feed URL otomatik güncellenir (anlık veritabanı sorgusu yapar,
      cache 5 dakika).
   3. İlan üzerinde değişiklik yaptığınız anda updated_at güncellenir;
      101evler bir sonraki çağrıda lastupdate farklı olduğu için
      güncellemeyi alır.
   4. İlanı 101evler'den çekmek için: checkbox'tan işareti kaldır VEYA
      yayın durumunu HIDDEN/DRAFT yap.
      (101evler eski kayıtları nasıl temizliyor? D maddesini sor.)

101evler tarafında:
   1. Verdiğimiz feed URL'ini sistemleri belirli aralıklarla GET çeker.
   2. <ad_key> ile mevcut ilan eşleşmesi yapar.
       - Yeni ad_key → yeni ilan oluştur
       - Aynı ad_key + farklı lastupdate → güncelle
       - Aynı ad_key + aynı lastupdate → atla
   3. Hatalar (zorunlu alan eksik, kur tanınmıyor, vs.) onların
      tarafında loglanır.
