# Alfa Emlak Web

Next.js tabanlı Alfa Emlak sitesi ve yönetim paneli.

## Geliştirme

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) adresinde açılır.

Ortam değişkenleri için `.env.example` dosyasına bakın.
